Superior Speedとは

Superior Speedは、Web制作者向けのファイル軽量化変換ツールです。画像・動画・音声といった各種ファイルを、Webサイトに適した軽量なフォーマットへ手元で変換できます。

WordPressプラグイン（EWWW Image Optimizerなど）に頼らず、アップロード前に自分の手元でファイルを軽量化できることを目指しています。

対応フォーマット

  • Phase 1（現在）: 画像（JPG / PNG など）→ WebP 変換に対応しています。
  • Phase 2（今後追加予定）: 動画 → WebM 変換を追加予定です。
  • Phase 3（今後追加予定）: 音声 → Opus 変換を追加予定です。

対応環境

  • 推奨ブラウザ：パソコン版の Chrome / Edge / Firefox（Safari・iPhone・iPad は WebP の書き出しに非対応です）
  • WebPへの書き出しに対応していないブラウザでは、ページ上部に案内が表示され、変換ボタンは押せなくなります。

プライバシーについて

  • すべてのファイル処理はお使いのブラウザ内で完結します。ファイルがサーバーに送信されることは一切ありません。
  • 位置情報などのメタデータは削除されます。画像はブラウザ内で描き直してから書き出すため、写真の撮影位置（GPS）や撮影機種などのEXIFメタデータは変換後のファイルに含まれません。
  • 本ツールは静的サイトとして構成されており、バックエンドサーバーを持ちません。
  • 変換後のファイルはブラウザを閉じる、またはページを再読み込みすると失われます。必要なファイルは都度ダウンロードしてください。
