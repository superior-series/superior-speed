# Superior Speed

Web制作者向けの「ファイル軽量化変換ツール」です。画像・動画・音声を、Webサイトに適した軽量なフォーマットへ手元で変換できます。

Superior Series の一員です（Superior Stock / Superior Rename / Superior Download と同じ認証基盤・デザイン言語を共有しています）。

## 特徴

- **完全にブラウザ内で処理** — ファイルはどこにもアップロードされません。プライバシーを守りながら変換できます。
- **サーバー不要** — 完全に静的なサイトとして構成されており、GitHub Pages でそのまま公開できます。
- **Web用ファイル名自動整形** — 日本語ファイル名やスペースを含むファイル名を、Webに適した半角英数字＋ハイフンの形式に自動整形できます。

## 対応フォーマット（Phase 1・現在のバージョン）

- 画像: JPG / PNG など → **WebP**

## 今後のロードマップ

- Phase 2: 動画 → WebM
- Phase 3: 音声 → Opus

## 使い方

1. ログイン後、「画像 → WebP」タブを開きます。
2. 変換したい画像をドラッグ&ドロップ、またはクリックして選択します（複数ファイル可）。
3. 必要に応じて各ファイルの「新しいファイル名」を入力します（空欄なら元のファイル名を引き継ぎます）。
4. 画質（50〜100）、最大幅の制限（デフォルト1920px）を設定します。
5. 「変換する」を押すと、ブラウザ内でWebPへの変換が実行されます。
6. 変換結果（元サイズ→変換後サイズ、削減率）を確認し、個別またはまとめてダウンロードします。

## ローカルでの動作確認

`file://` で直接開くと一部のブラウザAPIが正しく動作しないため、簡易HTTPサーバー経由で確認してください。

```bash
cd superior-speed
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いて確認します。

## 技術構成

- 完全ブラウザ完結型の静的サイト（サーバーサイド処理なし）
- 画像変換: ブラウザ標準の Canvas API（`canvas.toBlob(callback, 'image/webp', quality)`）
- 認証: Superior Series共通の Apps Auth 認証
